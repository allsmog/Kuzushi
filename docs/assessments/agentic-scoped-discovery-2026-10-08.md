# Exact scoped agentic discovery, October 8, 2026

The agentic adapter now consumes one accepted discovery boundary through shared
prepared dispatch. Its initial snippets come from literal discovery and shared
context membership. Model file tools enforce the same file union, with an
acknowledged digest before the query and in its executing response. A target
override cannot rebind accepted paths to another repository. Source drift and
unsupported runtime acknowledgement refuse execution before a model request.

The standard strategy supports this contract with `mcps=false` and no
include/exclude patterns. The job mounts Read, LS, Glob and Grep. Membership is
bounded to 100,000 literal files and 8 MiB serialized data. Listing and search
select accepted members directly; they do not walk unrelated repository files.
File reads reject symlink aliases and changed in-root path bindings. Preparation
retains its own snippet/read limits. Later agent reads remain separately bounded
by their existing tool behavior, not by the snippet byte limit.

Inherited source files supply context without becoming duplicate discovery work.
Observations outside discovery stay in `outOfScopeObservations` in canonical run
results. They are excluded from that job's findings ledger and cannot create
jobs. Scan and detailed Report disclose their count. This does not establish
that these observations are valid findings or that the full repository was
covered. Human decisions remain independent from recurrence.
