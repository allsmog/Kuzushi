# Strategy controls and the complete learning journey

Standard `agentic-sast:scan` accepted chunked-only settings that its executor
did not consume. Preparation-only probes admitted `dryRun: true`, a scope
file, retry IDs, a dollar stop and other chunk controls. No discovery was run
to demonstrate the defect. Accepting an ignored planning, scope or spending
choice was sufficient to require a repair.

Shared preparation now rejects all eleven chunked-only controls for standard
discovery. The validator derives their names from the same descriptor group
that declares them. It checks stored and explicit values before runtime work.
The error identifies the setting and offers removal or review of a separate
explicit chunked job. Nothing changes strategy, model, scope or allowance
automatically. Default standard discovery and accepted context remain intact.

The compatibility migration is documented in `RELEASING.md` and `modules.md`.
This does not qualify every inverse combination: standard-only controls on
the experimental chunked route still need a complete consumer audit. Legacy
chunked traversal, source isolation, precision and late-failure recovery retain
their previously documented limits.
