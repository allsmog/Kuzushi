# Exact scanner text in finite studies

An immutable threat-model revision did not pin its rendered scanner text.
Equivalence recorded the package version, so a renderer change within that
version could change a later pass without changing the approved input.

Model-backed discovery and Review preparation now save `threatModelDigestRef`
through the existing content store. Its version-1 document records target,
source identity, exact context revision, included text or absence, text hash,
limits and omissions. Existing input fingerprints bind the reference into
fixed jobs and approval. The 512 KiB serialized bound covers storage; token
and dollar limits remain the allowance adapter's responsibility.

Execution authenticates the object and selected revision, rechecks source and
reviewed-lesson eligibility, then consumes the saved bytes. It never substitutes
the current renderer. Active-context changes cannot redirect a job. Missing,
corrupt, oversized, foreign and mismatched content fails explicitly. Source
drift prevents execution while keeping authenticated historical reading
available. Legacy approved model work without this binding requires a new
reviewed plan, retaining prior attempts and spending.

The study Context picker reads its matching receipt and labels saved text,
source state, limits and included request text separately from the full
document. Other selections use their own revision preview. New context choices
clear the generated reference before preparation. Direct unbudgeted calls retain
compatibility rendering. Imported historical patterns now remain unverified
leads that need independent source assessment. Warning punctuation changes
apply to new projections; saved projections retain their original bytes.
