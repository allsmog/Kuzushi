The audit found and corrected a spending gap in four optional assessment
actions. It also prevents those auxiliary actions from publishing primary Scan
results and keeps configured experimental adapters out of Core discovery.
This checkpoint does not qualify all internal tools or compliance accuracy.

configured catalog has 128 visible tools; default Core discovery still has 79.

dispatch names. The optional active-testing actions were not executed.

cannot qualify that independent implementation.

## Assessment allowance and phase corrections

`shinsa:scan`, `shinsa:quick-check`, `shinsa:nist-scan` and
`shinsa:nist-quick-check` previously declared model-backed target writes without
an allowance category. The shared admission guard therefore did not require an
investigation allowance. The corrected descriptors declare Discovery accounting
and the canonical `allowanceRef` option. Artifact-write consent remains separate.
All four actions refuse unbound requests before a model call or output directory.
They cannot borrow an inherited Review binding.

The request supplies repository snippets and explicitly permits no agent tools.
The compatibility sampler includes at most 100 code files and 4,096 bytes per
file. Markdown and other unsupported extensions are omitted. This sampling is
not accepted discovery-scope enforcement, immutable context isolation or a
complete compliance assessment. Model usefulness remains unqualified.

Assessment and framework-list actions are auxiliary. They retain observations
and authorized report artifacts without creating primary Scan checkpoints. A
native test caught the previous checkpoint trapping subsequent commands behind
Scan result acceptance. Descriptor phase-result flags now prevent that trap.

Seven new shared-dispatch contracts cover all four modes, explicit allowance,
protected Review capacity, inherited-category refusal, missing dependencies,
malformed output and legacy descriptor semantics. Malformed output spends its
admitted call. A structured-output repair attempt must reserve capacity too;
with no unprotected capacity left, it cannot reach transport or consume Review.
No finding or report is fabricated after that failure.
