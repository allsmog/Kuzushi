# Shared model admission

Shared prepared dispatch previously let an in-scope model-backed tool execute
when `allowanceRef` was absent. Direct shell/run invocations could therefore
bypass investigation accounting. They now need an approved reference before the
executor starts. The selected model still must be explicit; missing-model
diagnostics retain their no-fallback remedy.

## Inherited work and compatibility

Approved Scan jobs dispatch child engines without copying governance fields
into engine parsers or prompts. `AgentRuntime::allowance_binding()` exposes the
already-bound host receipt for that case. Routing, ownership and trace wrappers
forward it. Shared dispatch validates the workspace ledger, same investigation
and work, revision, model and remaining capacity. Another workspace, a changed
model, a changed approval or an exhausted category refuses before another
provider call. Adapters continue to reserve every actual request atomically.
The getter does not reserve calls, authorize extra jobs or replace accounting.

Explicit deterministic context remains available with a supplied runtime and no
model allowance. Synthetic registry/context fixtures now approve finite limits
and meter their simulated calls rather than depending on the old bypass. Their
outputs remain labeled synthetic and make no real provider request.

The operator handbook now documents twelve existing context, grouping, source
review, relationship and lesson actions that were missing from its catalog.
This repairs discoverability and its registry contract; it does not promote
those tools or establish their full functionality.

## Remaining acceptance

This increment covers shared tool dispatch. Direct runtime/session entry points
that do not pass through this boundary still need accounting and a usable
approval journey. Raw runtime query APIs are not globally guarded by this change.
Model-backed fixed jobs still require their approved canonical inputs; a runtime
receipt alone does not establish scope or source coverage. Complete input/phase
qualification, model usefulness, large-repository performance, live AI scope
division, context experiments, lessons and full reference-product UX acceptance
remain open. The separate one-request Review repair-validation draft is still
unapproved and unstarted. No broad delivery milestone closes.
