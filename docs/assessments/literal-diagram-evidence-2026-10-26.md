# Literal diagram evidence and short terminal bodies

The focused DFD context graph printed source references as raw text while the
context reader quoted them. Edge spaces and embedded line breaks could make a
recorded file path hard to distinguish from another path. The native journey
also found that at 40 columns by 12 rows, stacked bordered panels hid the entire
evidence row after shell chrome consumed the available height.

The context reader and focused graph now share `DfdSecurityItem::evidence_label`.
Recorded path references use JSON string quoting; descriptive evidence stays
readable. This changes presentation only. Original evidence, file membership,
finding filters and scan inputs retain their literal bytes. Bodies shorter than
nine rows show the selected element, annotation position and evidence before the
description, without spending rows on separate bordered groups.

The change adds no tool options, persisted fields, model work, approved jobs or
automatic follow-up actions. The earlier 50-file historical lesson checkpoint
remains staged unchanged. This increment is separate working-tree work.
