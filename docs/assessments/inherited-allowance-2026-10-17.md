The module audit reproduced a shared accounting defect. A model-backed
`context:build` child accepted a runtime bound to Review work. Admission checked
the inherited ledger and capacity but only compared work categories for target
writes and external actions. A workspace child could therefore be admitted
under the parent's category. The retained pre-fix test fails with
`context:build reused Review accounting for Some(Context)`.

Shared prepared dispatch now checks the resolved child category for every
supported inherited model invocation. Context, Scope, Discovery, Review, Report
and Learning remain distinct. Mismatches preserve the allowance refusal class
and state the required category, inherited category and deliberate next step.
Refusal precedes executor collection, provider transport and reservations. Matching
work retains its wrapper. No model, category, scope or runtime is substituted.
Model-free context work remains available without consuming the parent binding.
Explicit references, fixed-plan admission, atomic reservations, retries, unknown
cost handling and revision checks retain their existing paths.

assessment contract now checks the more precise Discovery/Review refusal copy;
its earlier copy-only failure is retained. No guard was weakened to pass it.
