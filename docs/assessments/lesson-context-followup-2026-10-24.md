# Reviewed context into a bounded follow-up

After accepting a lesson and creating its inactive context copy, operators had
to leave Lessons, recreate a Scan draft, locate the copy and reconnect spending
history. The shell now exposes `s Plan follow-up with saved context`. It opens
the existing finite planner with the exact saved reference and declared source,
engine and prompt choices. The draft defaults to three passes, one worker and
one attempt per job. It creates no plan or approval, and Back restores Lessons.

The shared Core reader authenticates accepted lesson snapshots and reads their
source-run accounting. Current investigation limits, spent calls and unresolved
reservations survive the handoff. Missing recorded accounting stops preparation;
historical records without accounting disclose unknown consumption. Multiple
source investigations require a deliberate current investigation. An open study,
active work or pending context copy prevents replacement. Retirement and changed
context hashes block reuse. No global context or finding verdict is changed.

The source overview identifies the selected draft context before target details,
without presenting it as frozen or approved. Tall stacked planners show all
twelve choices when the menu and detail region both fit. The previous 80x24,
60x20 and 40x12 allocations remain unchanged. Model-guided engines read lessons;
native scanners keep their declared rules. No recursive jobs or variant searches
are created by this action.
