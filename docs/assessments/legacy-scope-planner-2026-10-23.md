# Bounded compatibility planning, October 23, 2026

Prepared dispatch exposed defects that successful raw planner envelopes had
hidden. The legacy scope-file adapter recursively followed directories without
an entry budget, containment check or cancellation. It could publish an outside
path, a canceled plan or an ambiguous line-delimited filename. Three owned
regressions reproduced those outcomes before the implementation changed.

The planner now derives scope files from one bounded repository inventory per
plan. It retains the existing 100,000-entry, 512 MiB overall and 256 KiB per-file
inspection limits. Complete file enumeration is required; content-prefix
truncation remains a separate disclosed condition. The saved `scopeInventory`
receipt authenticates the full inventory artifact and reports omissions and
inspection limits. Root files and literal paths survive; symlinks do not become
discovery members. Total memberships across unique shards cannot exceed
100,000, each scope list must fit its consumer's 4 MiB limit, and the inventory
artifact cannot exceed 16 MiB. This does not freeze source for execution.

Every generated child passes shared preparation before a plan is published.
That exposed the obsolete standard-agentic adapter: `scopeFile` requires the
chunked strategy, which cannot honor standard context and prompt controls. The
planner refuses that combination rather than changing strategy. An explicitly
selected `full-mode:hunt` can consume the legacy scope file without threat
seasoning. New investigations should use `campaign:study` and accepted scopes.

Planning is auxiliary Map work, with `phase_result=false`. It grants no work or
allowance and cannot establish Map completion. Contained atomic writers publish
the files. A cancellable lock serializes legacy planners for the same campaign
ID; an existing plan refuses replacement before its scope files change. Owned
tests preserve the exact prior plan and inventory after source drift and prove
one winner for concurrent publication. Existing plan and scope-line formats
remain readable; the inventory receipt is additive.

The TUI receipt now leads with draft status, workload and unapproved work.
Artifact paths are relative to the selected target and follow the limitations;
the full absolute plan path remains in structured data. A short summary avoids
repeating the entire saved output on wide terminals. The saved output retains
the named unseasoned documents and complete qualifications.
