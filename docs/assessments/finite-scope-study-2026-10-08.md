# Finite accepted scope studies, October 8, 2026

Operators can mark several accepted discovery boundaries and prepare one fixed
scope study through the existing campaign planner and dispatcher. Each selected
boundary supplies an explicit pass count, defaulting to three. One worker is the
default. Planning authenticates every source-bound scope, freezes context and
configuration, and records unplanned siblings. No worker can append jobs,
subdivide boundaries, or discover siblings automatically.

`campaign:study` exposes `scopeProposalRef` and `scopeCases`. The additive
`scope-study` format permits one to nine selected boundaries and at most 100
jobs. Scope cases inherit frozen common context or carry an exact immutable
override or explicit omission. Missing context and explicit null remain distinct
before freezing. Context experiments and historical baseline comparisons are
separate studies. Shared file membership remains context only unless selected
for discovery in the accepted proposal.

Approval authenticates the complete job list, model, runtime, source, context,
configuration, and unplanned boundary list. It uses the existing durable work
and call reservation ledger. Changed source and altered jobs fail; cancellation
and failures retain their approved attempt limits. The existing dispatcher
publishes results for explicit Scan acceptance. Per-scope recurrence counts use
only that boundary's completed passes, while the evidence ledger and allowance
remain shared. No absence or recurrence count establishes a finding verdict or
a fix at another SHA.

The TUI offers Space to mark boundaries and p to review their combined study.
Back preserves the selection and reading origin. Engine selection validates the
accepted-file contract, including the explicit constrained file-tool choice.
The Source panel shows selected boundaries, total jobs and actual frozen context.
Report shows separate boundary denominators, unplanned siblings, source identity,
model and shared spending. Expanded details preserve individual scope references
and source limitations. Case summaries precede lengthy boundary provenance.
Existing context studies retain their format and execution behavior.
