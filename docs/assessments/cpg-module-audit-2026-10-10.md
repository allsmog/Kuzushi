## Operator behavior and curation

`cpg:build` now supplies auxiliary Map evidence and is Labs. Exact names,
options, aliases and graph locations remain available. Its descriptor cannot
publish a Map checkpoint, including when a plan explicitly names the tool.
Context review and acceptance remain separate. No implementation is deleted.

The graph provides useful persisted function/call structure: actual Go source
produces nonempty methods and a decodable artifact, which the graph loader and
statistics reader consume. Directory scoping excludes sibling source and keeps
the artifact under the workspace root. Content edits invalidate reuse. Direct
execution needs neither a model runtime, context index nor findings store.
The `context:build` DAG dependency is metadata, not executed ordering.

Labs is evidence-backed curation. Language detection repeats recursive walks;
source census reads whole source files before applying the frontend file cap.
Fresh cached loads can exceed that construction cap. Enumeration, aggregate
reads, import size, decoder/frontend work and mid-operation cancellation are not
reliably bounded. Prefer a small explicit `subdir`. This increment reports these
limits and removes the default recommendation; it does not qualify large repos.

A failure before any reported graph remains failure. Failure after a saved
graph stops the requested language sequence and returns a partial receipt with
those graphs and `stopReason`. Build data adds the actual `sourceRoot`. Reading
copy leads with scope, actual parsed counts and relative graph paths, followed
by context acceptance and collection limitations. The file-cap error now places
observed files and the cap before its scope path. Singular counts read naturally.

Graph import refuses `languages`, `subdir` and `maxSourceFiles` instead of
silently ignoring them. Remove stored or inline build options before import.
Import retains its current-shape/format check and adds
`currentCheckoutApplicability: "not_assessed"`. Decoding a graph does not prove
its source matches the current checkout. Persisted graph formats are unchanged.
