# Bounded taint catalog drafts

The previous catalog generator started model-backed work under a Read/Scan
label and immediately replaced active configuration. The shell could generate
it implicitly before a hunt. Recursive source walking, silent context-read
omissions and permissive normalization made its resource and evidence contract
unreliable. This action was model-backed despite the preceding checkpoint's
next-work description calling it deterministic.

Generation now uses one no-tools model turn, Context allowance and bounded
shared inventory/source prefixes. Source and context omissions are explicit,
Unicode handling preserves text boundaries, and the actual supplied input and
system instructions survive in a versioned immutable draft. Only source-grounded
signals and valid marker patterns can enter that draft. Priority zero remains
zero. Invalid, excessive, canceled or source-drifted output cannot replace the
active profile or produce an acceptable draft. Bounded raw text remains in the
result even when it is not JSON. No repair request is made.

Generation is hidden Labs auxiliary Map work. New runtime-free Core read and
accept actions provide a distinct operator contribution: exact historical
inspection and explicit activation with source and active-version checks.
Neither action completes Map or starts discovery. Partial input requires an
acknowledgement. Prior active bytes and accepted versions are retained in the
existing content store. After inspecting an intervening edit, an operator can
approve replacement of exactly that version without paying for regeneration.

Actual planners now consume an exact accepted catalog digest independently of
active edits. Source-bound profiles refuse source drift. A draft hash cannot
stand in for an accepted catalog, malformed saved text cannot silently select
built-in rules, and `catalogDigestRef=static` makes that choice explicit.
The SAST umbrella declares and preserves the same option through its actual
child-input filter. Legacy import JSON and the active file path remain readable.
Legacy metadata does not establish current source coverage.

Shell prerequisite execution no longer generates a catalog or context for a
catalog action. A hunt retains its independent deterministic context prerequisite.
Catalog DAG metadata declares no dependency and is not credited as orchestration.
The acceptance card names the actual workspace, exact draft, partial-input
acknowledgement and absence of new model or scan work.
