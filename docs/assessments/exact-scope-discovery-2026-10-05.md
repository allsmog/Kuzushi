# Exact accepted scope discovery, 2026-10-05

This increment connects accepted scope revisions to one selected-scope study and
two native discovery adapters. It does not complete the monorepo or model-backed
investigation workflow.

## Supported behavior

`sast:scan` declares optional `scanScopeRef`. Shared prepared dispatch authenticates
the committed accepted revision, current content and Git revision, exact scope
identity and engine capability. A simultaneous `paths` value is refused. The
resolver reads full immutable inventory membership, applies exclusions and keeps
literal root files. Its separate context-file list follows direct dependencies
and context-only shared membership without recursive expansion. Native scanners
do not consume that context list.

Secret scanning reads only selected regular files. Cancellation, finding caps,
unreadable source and skipped binary/oversized files remain incomplete. Semgrep
uses literal file arguments in groups of 64 and validates its reported scanned
paths. Missing or malformed coverage, omitted files, outside paths and failed
batches cannot establish complete coverage. Completed batch observations survive
a later failure. Native settlement preserves completed engines while retaining
canceled partial observations and leaving later engines unstarted.

Model-backed engines and other native adapters currently lack the exact-file
contract. They refuse work instead of broadening discovery. Whole-repository
investigation remains a separately reviewed job through existing interfaces.

The existing version-1 homogeneous study format repeats one accepted boundary.
Each fixed job retains `scanScopeRef`; the reference contributes to equivalence.
The public `ScanRunOptions` layout is unchanged. New `ScanEngine` methods have
compatibility defaults. These changes add no automatic jobs or subdivision.

## TUI behavior

Accepted scope review offers **Plan selected scope** and `p`. It supplies the
workflow-owned reference, preserves configured engines and opens the existing
three-pass, one-worker form. Unaccepted or context-only boundaries cannot open
a discovery study. Back restores the scope selection and scroll position.

Options preview uses the shared descriptor preparation without reading scope
objects or hashing source. Admission and source checks run in the cancellable
campaign worker. The selected Map or presented catalog context remains an
immutable input rather than changing the globally active model.

Scan receipts direct reruns to review saved owner options. They no longer suggest
an empty engine command that would omit scope. Scope review describes its own
authority without claiming separately saved studies have not been compiled.
