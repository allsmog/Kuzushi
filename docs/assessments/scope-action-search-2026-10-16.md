# Search scope actions without changing approved work

The scope action menu now exposes `/ search`. Typing filters the existing
actions; arrows choose a result and Enter selects its original action identity.
Esc first clears search, then closes the menu. Pasted lines become search terms
without entering the composer or submitting an action. No matches means no
selected action and Enter performs no work. A refused action preserves its query
and selection. Filtering itself creates no artifact, job, approval or model call.

The query uses the shared Unicode field editor. Its cursor remains visible in
the title while the original source-status row stays visible below it. Narrow
controls name paging as well as selection and recovery. Paging the description
keeps the selected action, query, boundary and composer unchanged. Plain output
uses the same filtered choices and retains query and source provenance.

Action names and executor indices remain canonical. Selecting a filtered result
uses the existing scope edit or planning path, including its source checks and
separate acceptance, job and allowance approvals. This does not add a global
findings scope filter or change public module contracts.
