## Failure and resource contracts

Saved scope must be a valid object with usable known fields. Missing defaults
remain compatible, but malformed fields do not silently reset the draft. Reads
and writes share the 8 MiB scope limit. Clear cannot be combined with metadata
updates. Output paths are preflighted against symlinks before assessment work.

Local evidence is a regular nonlinked file capped at 32 MiB. Text capture retains
at most 256000 source bytes, ending on a valid Unicode boundary for valid UTF-8.
Invalid text replacement and truncation are disclosed. Capture receipts add
source, captured and stored text sizes, a truncation flag and a digest of local
bytes at capture time. That digest does not establish current source identity.
Opaque document IDs avoid same-millisecond collisions; earlier IDs remain readable.
URL references are not fetched and have unknown source size. Binary input keeps
metadata only. PDF and Office extraction is not implemented. Target-local stored
options cannot supply any external source alias, including legacy `input`.

Assessment requires parsed text and at most 512 KiB of joined prompt context.
Failure of either prerequisite starts no request or completed risk report.
The request uses the explicit selected model, no agent tools or MCPs and at
most one turn per request. Shared structured-output repair still needs approved
capacity before another request. Missing runtime errors no longer prescribe an
unrelated backend. The result says model opinion, not repository scan or accepted
threat model. The local draft remains mutable. Late multifile write failure,
complete cancellation, immutable external-document snapshots and real-model
quality are not qualified, so assessment stays Labs.
