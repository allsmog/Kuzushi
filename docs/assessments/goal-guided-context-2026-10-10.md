# Reviewed goals can guide an approved context draft

Brief storage and selection previously recorded only operator metadata. New
context planning now has an explicit guidance choice. It defaults off. Operators
select an exact reviewed goal, enable guidance, inspect its text and then review
the finite plan and allowance. Saving a goal or selecting it still makes no
model request and changes no scanner input or finding decision.

## Shared contract and actual consumption

`campaign:context-study useBriefGuidance=true` requires `briefRef` and supports
fresh inactive repository or file-group context builds. Other generation tools
retain their own explicit guidance inputs. Nested input cannot secretly select
another goal. The planner authenticates the exact revision, binds declared
`threat-model:build operatorBriefRef` into the child and includes the full brief
in its immutable plan. Reading verifies that child and plan references agree.

Shared allowance dispatch treats goal-guided context like file-group context:
an explicit allowance and fixed approved work are required. It binds runtime
accounting and claims exact work before the engine. Governance fields remain
outside engine parsers and prompts. Internal attempts still reserve calls from
the shared allowance; the change grants no additional jobs or reservations.

The source-only generator loads the authenticated goal from the workspace's
content store. Entire text, bounded to 8192 UTF-8 bytes, enters a dedicated
priorities/questions section distinct from source evidence. No current head or
global context is substituted. Generated context provenance records the actual
reference, text byte count and non-evidence/non-verdict purpose. Model claims
cannot supply this reserved provenance. The result remains inactive.

The real repository generator with a stub runtime proves revision 1 reaches
the request after current head revision 2. It emits an inactive context with
matching provenance, one reserved/settled call, no observations and no active
context change. A separate scoped generator test retains disjoint discovery
and shared files, omits unselected source and preserves active context. These
are actual executors with stub providers, not live model-quality evidence.
