# Diagram evidence to a bounded study, October 18, 2026

DFD elements now offer an explicit scan-planning action. The operator can review
the exact source paths and displayed immutable context before preparing the
existing finite study. Opening this form starts no jobs and grants no allowance.
This repairs the missing diagram-to-discovery handoff without adding another

## Operator behavior

In the Map DFD or its full-frame view, Navigate mode owns `s plan scan`. A focused
context row narrows the selection to that row's evidence. The inspected immutable
context diagram offers the same action for its selected element. Nodes, flows
and trust boundaries use their recorded file links; the action infers no paths.

The new form defaults to three passes, one worker and one attempt per job. Its
first detail names the diagram element, exact context revision and each quoted
source path. The existing full reader exposes the complete text at small sizes.
Engines, source, context, workload and allowance remain reviewable through normal
study controls. Preparation, approval and launch are separate actions.

The handoff preserves selected engine and prompt settings while replacing prior
source selection and frozen context-snapshot references. It binds the displayed
context revision, including an inactive inspected revision, without activating it
or rewriting the parent's scan input. Shared prepared dispatch validates actual
filesystem membership and engine scope support when freezing the plan. A
directory-only or repository-only engine cannot silently widen a selected file.

Empty or unverified links, invalid/outside paths, traversal and selections over
256 evidence paths refuse the handoff. Invalid members cannot be silently dropped
from a mixed selection. Literal path punctuation and meaningful spaces survive.
Planning another nested diagram study is refused until returning to the original
diagram. Workers cannot add work to the accepted fixed plan.

Back restores the diagram, selected element, detail reading position and parent
study draft. The return remains available after opening approved jobs. It retains
the parent's pass count, pending limits, inspected revision and composer draft.
Current durable accounting is reloaded after a prepared child, without replacing
those draft choices. A changed target cannot restore the earlier target's state.
These navigation positions are process-local; durable plan, context, work and
report recovery are separately verified across restart.
