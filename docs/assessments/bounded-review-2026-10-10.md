# Bounded finding review

and allowance machinery. It freezes 1 to 100 exact observation generations into
one Review job, with one worker and one attempt. Preparation preserves the
effective strategy, including bulk deep review. It binds accepted Map context or
an explicit omission, source identity, configuration and selected model.
Approval starts no jobs; the campaign's separate launch action starts its job.

The shell's selected triage step now opens a Review form. Visible controls choose
model, context and strategy, edit total/protected calls, inspect exact options
and read the entire draft. Cancel retains the original task and composer.
Opening approved jobs removes only the replaced task; other selected work stays
paused. Named recovery restores the same plan and accounting. Review inherits
historical Map spending across source changes, while old context cannot satisfy
current-source acceptance. Standalone legacy triage remains compatible.
