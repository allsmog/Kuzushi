## Cross-cutting / known issues from the comprehensive fix

1. **Multi-agent collision risk** — the v0.21 series was built while a
   parallel implementation session was actively editing many of the same files.
   Several commits bundle local WIP renames (`threat-hunt` →
   `carlini-threat-hunt`) alongside the targeted fixes. Reviewers should
   spot-check that the WIP is consistent with where the rename should
   land.

2. **Branch naming inconsistency** — Phases 1-5 all share branch
   `fix/v0.21-phase-1` because that was the active branch at commit time.
   Phase 0 is on its own `fix/v0.21-phase-0`. Pre-merge cleanup: rename the
   first commit branch to `fix/v0.21-comprehensive` or split phases into
   named branches via `git branch <name> <commit-sha>`.

3. **Type errors in untracked local WIP** — `pnpm typecheck` against the
   current working tree fails on
   `src/modules/taint-iris-next/agent.ts(224,5)` (readonly array
   assignability). This is in untracked module work, not in any
   v0.21 commit. The 6 v0.21 commits all individually pass `pnpm typecheck`
   when the working tree is clean of the untracked WIP.

4. **Repo housekeeping warnings** — git emits warnings about unreachable
   loose objects and a stale `.git/gc.log`. Run `git prune` after the
   v0.21 series merges.
