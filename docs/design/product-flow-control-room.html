The five new components

Each ships as a real React component (src/<Name>.tsx) with a typed prop contract and a JSDoc example — the same shape as the kit's existing eight.

PhaseRail
The 組→崩→作→掛→report spine. done ✓, the single current phase accent + ▸ + upper-cased, todo subtle — state from engagement reality, never fabricated.
組 aim ✓ 崩 HUNT ▸ 作 confirm 掛 fix ▪ report
ProofBadge
The confirmed-vs-guess trust marker for a finding: ✓ confirmed / ◇ candidate / ? unverified / ! rejected. Put one on every ledger row.
✓ confirmed ◇ candidate ? unverified ! rejected
MeterBar
A ▓▓▓░░ meter for a bounded quantity — budget, coverage, a verify pass. Filled cells take a tone (warn/danger near the cap); cost is always on screen.
budget ▓▓▓░░░░░░░░░ $0.85 / $2.00 coverage ▓▓▓▓▓▓▓▓▓░░░░░░░ 7 / 12
ProposalRow
One priced, budget-gated hunt proposal: id · title · generator · $price · yield, a keep/skip hint, and a proposed ▸ / kept ✓ / skipped ✗ marker.
✓ P-001 incomplete-fix hunt commits · $0.40 · yield .82 ▸ P-002 SSRF reachability threat-model · $0.30 · yield .74 [k/s] ✗ P-004 dep footguns intel · $0.15 · yield .40
EngineChips
The per-scan engine-enablement row — the control plane's analysis toggles. Enabled reads primary + ✓ with a cost estimate; disabled reads muted + ○.
engines cpg ✓ ~40s codeql ○ lsp ○

To publish into the “Kuzushi TUI Kit” Claude Design project: run /design-sync on the package — it rebuilds the bundle, generates the preview cards, and pushes the five new components alongside the existing eight.
Note: the real kit renders in JetBrains Mono; this preview falls back to the platform monospace font (a CDN font can't load under the artifact sandbox), so glyph spacing differs slightly from the shipped look.
